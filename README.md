# טלפרומפטר קולי · פרקטי AI

טלפרומפטר שגולל את הטקסט לפי הקצב שבו אתה מקריא, ולא במהירות קבועה. בגרסת המחשב החלון צף מתחת למצלמה ולא מופיע בהקלטות מסך או בשיתופי מסך (OBS, Zoom, Loom, Teams ועוד).

## ⬇️ הורדה
| | |
|---|---|
| **גרסת מחשב ל-Windows** (חלון צף, מוסתר מהקלטות) | [הורדת קובץ ההתקנה](https://github.com/bar148/practice-ai-teleprompter/releases/latest/download/Practice-AI-Teleprompter-Setup.exe) |
| **גרסת דפדפן** (בלי התקנה, ב-Chrome או ב-Edge) | [פתיחה בדפדפן](https://bar148.github.io/practice-ai-teleprompter/) |

החלון של גרסת הדפדפן **כן** מופיע בהקלטת מסך. להקלטות צריך את גרסת המחשב.

## התקנה (Windows)
1. מריצים את `Practice-AI-Teleprompter-Setup.exe`.
2. אם מופיעה ההודעה "Windows protected your PC", לוחצים על **More info** ואז על **Run anyway**. ההודעה מופיעה כי הקובץ לא חתום דיגיטלית.
3. בשולחן העבודה נוצר קיצור דרך בשם **טלפרומפטר פרקטי AI**.

דרישות: Windows 10 או 11 עם Edge או Chrome (Edge מותקן בכל Windows), מיקרופון וחיבור לאינטרנט.
מי שמותקן אצלו Whisper מקומי יכול לעבוד גם בלי אינטרנט.

## איך משתמשים
- מדביקים טקסט ולוחצים **התחל**. אחרי ספירה לאחור של 3-2-1 מתחילים להקריא.
- הטקסט מתקדם לפי הקול. אם עוצרים הוא מחכה, ואם מדלגים הוא מוצא את המקום.
- אם חוזרים אחורה ומקריאים משפט שוב (טייק חוזר), הטלפרומפטר מזהה את זה, חוזר איתך ורושם את זה.
- אפשר לעבור ל**מהירות קבועה** בלחיצה על הכפתור 🎙/⏱.

### סימונים בתוך הטקסט
| כותבים | מה קורה |
|---|---|
| `# כותרת` | כותרת פרק. היא לא נקראת בקול, ונכנסת לרשימת הפרקים ליוטיוב |
| `[חייך]` | הערה לעצמך. מוצגת בצבע אחר ולא נקראת בקול |
| `[שקף]` | מעביר שקף במצגת כשמגיעים לשם (צריך להפעיל את האפשרות בהגדרות) |

### קיצורי מקשים (בזמן ההקראה, עובדים גם כשאתה בתוך תוכנה אחרת)
| מקשים | פעולה |
|---|---|
| F9 | הפעלה ועצירה |
| Ctrl+Alt+↑/↓ | שורה אחורה או קדימה |
| F10 | סימון טייק פסול |
| Ctrl+Alt+H | הסתרת החלון והחזרתו |

אם מקש מסוים כבר תפוס אצלך בתוכנה אחרת, האפליקציה עוברת לבד לצירוף פנוי. מסך העריכה מראה אילו מקשים היא קיבלה בפועל.
בנוסף, בפינה של החלון הצף יש כפתור ▶/❚❚ קבוע להפעלה ולעצירה.

### ייצוא אחרי ההקלטה
**⤓ ייצוא מההקראה האחרונה** יוצר:
- **כתוביות SRT** מתוך התסריט עצמו, עם הזמנים שבהם הקראת כל משפט.
- **פרקים ליוטיוב** מתוך הכותרות (`# ...`).
- **רשימת סימונים** של טייקים פסולים וטייקים חוזרים, עם זמנים, כדי לדעת איפה לחתוך.
